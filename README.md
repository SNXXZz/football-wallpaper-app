# Football Wallpaper App

A modern and simple football (soccer) wallpaper application with admin-only upload functionality.

## Features

✅ **Admin Panel** - Upload wallpapers (admin only)
✅ **League Pages** - Dedicated pages for World Cup, Champions League, etc.
✅ **Search Bar** - Find wallpapers by keywords
✅ **Responsive Grid** - 4-column layout for wallpapers
✅ **Modern Design** - Clean UI with smooth animations
✅ **Menu Navigation** - Contact admin, follow us, terms & conditions
✅ **File Upload** - Direct image upload (no URL pasting)

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion (animations)
- Express.js (backend)
- MongoDB
